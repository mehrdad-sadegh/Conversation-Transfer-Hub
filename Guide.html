انتقال مکالمه بین هوش‌های مصنوعیMove conversations between AIs

یک مکالمه‌ی کامل را به‌همراه context آن از یک هوش مصنوعی (ChatGPT، Claude، Gemini، DeepSeek…) به هوش مصنوعی دیگر منتقل کن — بدون جاافتادن اطلاعات و با حفظ کامل کدها. Carry a whole conversation — with its context intact and code preserved verbatim — from one AI (ChatGPT, Claude, Gemini, DeepSeek…) to another.

این برنامه چه کاری می‌کند؟What does this do?

OverviewThe big picture

وقتی با یک هوش مصنوعی طولانی گفتگو می‌کنی، کلی context ساخته می‌شود: هدف پروژه، تصمیم‌ها، کدها، محدودیت‌ها. اگر بخواهی ادامه‌ی کار را با یک AI دیگر پیش ببری، همه‌ی این‌ها از بین می‌رود. این برنامه همان مکالمه را می‌خواند، مهم‌هایش را بیرون می‌کشد و یک «بریفینگ آماده‌ی Paste» می‌سازد که می‌توانی مستقیم در AI مقصد بچسبانی. A long chat with an AI builds up a lot of context: the project goal, decisions, code, constraints. Switch to another AI and all of that is lost. This tool reads that conversation, pulls out what matters, and produces a paste-ready briefing you drop straight into the destination AI.

کار از دو بخش تشکیل شده که مکمل هم هستند: It comes in two complementary parts:

۱ / 1افزونه‌ی مرورگرBrowser extension

خواننده‌ی اصلی. داخل مرورگر خودت که توش لاگینی اجرا می‌شود، مکالمه‌ی باز را مستقیم می‌خواند. چون داخل حساب خودت کار می‌کند، نیازی به اعتماد به مرورگر ثالث نیست. The main reader. Runs inside your own browser where you're already signed in, and reads the open conversation directly — no third-party browser to trust.

ChatGPTClaudeDeepSeekGemini

۲ / 2نرم‌افزار دسکتاپ (هاب)Desktop app (hub)

اختیاری و برای کار حرفه‌ای‌تر. فایل یا متن مکالمه را می‌گیرد و امکان تحلیل، فشرده‌سازی، ویرایش context و بسته‌بندی می‌دهد. هیچ لاگینی نمی‌خواهد و کاملاً آفلاین است. Optional, for deeper work. Takes a file or pasted text and lets you analyze, compress, edit the context, and package it. No login, fully offline.

💡
برای کار روزمره فقط افزونه کافی است: مکالمه را بخوان، خروجی را کپی کن، در AI مقصد بچسبان. نرم‌افزار دسکتاپ وقتی به‌درد می‌خورد که بخواهی خروجی را دقیق‌تر ویرایش یا بایگانی کنی. For everyday use the extension alone is enough: read, copy, paste into the destination AI. The desktop app is for when you want to fine-tune or archive the result.

بخش ۱ — افزونه‌ی مرورگرPart 1 — The browser extension

نصب و استفادهInstall & use

نصب افزونه در کروم (یا Edge / Brave)Install in Chrome (or Edge / Brave)

  1. پوشه‌ی extension را آماده داشته باشHave the extension folder ready
    همان پوشه‌ای که فایل manifest.json داخلش است.
    The folder that contains manifest.json.
  2. به آدرس chrome://extensions بروOpen chrome://extensions
    این آدرس را در نوار آدرس مرورگر تایپ کن و Enter بزن.
    Type it in the address bar and press Enter.
  3. حالت توسعه‌دهنده (Developer mode) را روشن کنTurn on Developer mode
    کلید آن گوشه‌ی بالا-سمت راست صفحه است.
    The toggle is in the top-right corner.
  4. روی «Load unpacked» بزن و پوشه‌ی extension را انتخاب کنClick “Load unpacked” and pick the extension folder
    افزونه با آیکن خودش در نوار مرورگر ظاهر می‌شود.
    The extension appears with its own icon in the toolbar.
  5. آیکن را پین کنPin the icon
    روی آیکن پازل مرورگر بزن و افزونه را سنجاق کن تا همیشه در دسترس باشد.
    Click the puzzle icon and pin it so it's always one click away.
ℹ️
«Load unpacked» چون افزونه از فروشگاه نصب نشده لازم است و کاملاً عادی است. تا وقتی حالت توسعه‌دهنده روشن بماند، افزونه فعال است. “Load unpacked” is needed because the extension isn't from the Web Store — this is normal. It stays active as long as Developer mode is on.

خواندن یک مکالمهReading a conversation

  1. مکالمه را در AI مبدأ باز کنOpen the conversation in the source AI
    مثلاً وارد ChatGPT شو (لاگین باش) و همان چتی را که می‌خواهی منتقل کنی باز کن.
    E.g. go to ChatGPT (signed in) and open the exact chat you want to move.
  2. روی آیکن افزونه بزنClick the extension icon
    پنجره‌ی کوچک افزونه باز می‌شود و سرویس شناسایی‌شده را بالا نشان می‌دهد (مثلاً «ChatGPT») به‌همراه تعداد پیام، کد و تصمیم‌ها.
    The popup opens, shows the detected service (e.g. “ChatGPT”) and the count of messages, code blocks and decisions.
  3. «مقصد» و «حالت انتقال» را انتخاب کنPick “destination” and “transfer mode”
    مقصد = AuI که می‌خواهی ادامه بدهی. حالت = چقدر از مکالمه منتقل شود (پایین‌تر توضیح داده شده).
    Destination = the AI you'll continue in. Mode = how much to carry over (explained below).
  4. خروجی را کپی کنCopy the output
    متن آماده در کادر پایین ساخته می‌شود. دکمه‌ی «کپی» را بزن، یا با «دانلود .md / .json» ذخیره‌اش کن.
    The ready text appears in the box. Hit “Copy”, or save it with “Download .md / .json”.
  5. در AI مقصد بچسبانPaste into the destination AI
    یک چت جدید در AI مقصد باز کن و خروجی را به‌عنوان اولین پیام Paste کن. تمام.
    Open a new chat in the destination AI and paste it as your first message. Done.

دو نوع خروجیTwo output formats

.md — بریفینگBriefing
متن تمیز و خوانا که context و کل مکالمه را دارد. همین را مستقیم در AI مقصد Paste کن. گزینه‌ی پیش‌فرض و پیشنهادی. A clean, readable text holding the context and the whole transcript. Paste this straight into the destination AI. The recommended default.
.json — بستهPackage
فایل ساختاریافته‌ی .ai-transfer برای بایگانی یا باز کردن در نرم‌افزار دسکتاپ جهت ویرایش دقیق‌تر. A structured .ai-transfer file to archive, or to open in the desktop app for finer editing.

The first run may trigger Windows SmartScreen (the file isn't code-signed). Click More info → Run anyway. It doesn't mean anything is wrong with the app.

گردش کار در برنامهThe in-app workflow

  1. ورودی بدهGive it input
    یا متن خام مکالمه را Paste کن، یا فایل .ai-transfer / .json / .txt / .md را باز کن (یا روی کادر رها کن).
    Either paste the raw transcript, or open a .ai-transfer / .json / .txt / .md file (or drop it on the box).
  2. «تحلیل» را بزنClick “Analyze”
    آمار مکالمه، حجم تخمینی توکن، و اینکه AI مقصد چه قابلیت‌هایی دارد نمایش داده می‌شود.
    It shows conversation stats, estimated token size, and what the destination AI supports.
  3. حالت انتقال را انتخاب کنChoose a transfer mode
    کامل، هوشمند، فشرده، یا دلخواه (در حالت دلخواه خودت تیک می‌زنی چه چیزهایی برود).
    Full, Smart, Compact, or Custom (tick exactly what to include).
  4. Context را ویرایش کنEdit the context
    هدف پروژه، تصمیم‌ها، محدودیت‌ها، کارهای باقی‌مانده و… را قبل از تولید خروجی اصلاح کن. کدها عیناً حفظ می‌شوند و هرگز خلاصه نمی‌شوند.
    Fix the goal, decisions, constraints, open tasks and more before generating. Code is kept verbatim, never summarized.
  5. (اختیاری) دقیق‌سازی با AI(Optional) refine with AI
    اگر کلید API داشته باشی، برنامه می‌تواند context را دقیق‌تر کند. کلید روی همین کامپیوتر رمز می‌شود (DPAPI) و جز به همان سرویس جایی نمی‌رود.
    With your own API key, the app can sharpen the context. The key is encrypted on this PC (DPAPI) and only ever goes to that provider.
  6. خروجی را بگیرTake the output
    بین «بریفینگ» و «بسته» جابه‌جا شو، بعد «کپی» یا «ذخیره‌ی فایل» را بزن.
    Switch between “Briefing” and “Package”, then “Copy” or “Save file”.
🔒
هیچ‌چیز از این کامپیوتر خارج نمی‌شود، مگر درخواستی که خودت با کلید API خودت به AI بدهی. Nothing leaves this computer except a request you deliberately trigger with your own API key.

حالت‌های انتقالTransfer modes

چقدر از مکالمه منتقل شودHow much to carry over
کاملFull
همه‌چیز حفظ می‌شود — کل پیام‌ها بدون حذف. امن‌ترین انتخاب وقتی مطمئن نیستی چه چیزی مهم است.Keeps everything — every message, nothing dropped. Safest when you're unsure what matters.
هوشمندSmart
گپ‌وگفت‌های بی‌اهمیت و پیام‌های تکراری حذف می‌شوند، ولی مطالب مهم می‌مانند.Drops small talk and duplicate messages, keeps the substance.
فشردهCompact
فقط کد، تصمیم‌ها و context اصلی. برای وقتی که می‌خواهی خروجی خیلی کوتاه باشد.Only code, decisions and the core context. For when you need the output as short as possible.
دلخواه (فقط دسکتاپ)Custom (desktop only)
خودت تیک می‌زنی: پیام‌های خودت، پیام‌های AI، تصمیم‌ها، کد، فایل‌ها، context و…Tick exactly what goes in: your messages, AI messages, decisions, code, files, context and more.
💡
افزونه سه حالت دارد (کامل، هوشمند، فشرده). حالت «دلخواه» فقط در نرم‌افزار دسکتاپ هست. اگر شک داری، کامل را بزن. The extension has three modes (Full, Smart, Compact). “Custom” is desktop-only. When in doubt, choose Full.

حریم خصوصی و محدودیت‌هاPrivacy & limits

چه چیزی منتقل می‌شود و چه چیزی نهWhat moves and what doesn't
🔐
لوکال‌محور: افزونه مکالمه را از همان صفحه‌ی باز می‌خواند و همه‌چیز داخل مرورگر/کامپیوتر پردازش می‌شود. هیچ‌جا آپلود نمی‌شود، مگر اینکه خودت دقیق‌سازی با کلید API را فعال کنی. Local-first: the extension reads from the page you already have open and processes everything inside the browser/computer. Nothing is uploaded unless you yourself enable AI refine with your API key.
🧩
کد سالم می‌ماند: بلوک‌های کد عیناً و کامل منتقل می‌شوند و هرگز خلاصه یا دستکاری نمی‌شوند. Code stays intact: code blocks are carried verbatim and in full — never summarized or altered.
🖼️
عکس‌ها و فایل‌ها منتقل نمی‌شوند: محتوای تصاویر و فایل‌های ضمیمه قابل انتقال نیست؛ فقط به‌صورت نشانه‌ی [Image] یا [Attachment] در متن ثبت می‌شود تا بدانی آنجا چیزی بوده. اگر فایلی مهم است، باید دستی در AI مقصد دوباره آپلودش کنی. Images & files don't transfer: the content of images and attachments can't be moved; they appear only as an [Image] or [Attachment] marker so you know something was there. Re-upload any important file manually in the destination AI.
📶
پشتیبانی سرویس‌ها: ChatGPT، Claude و DeepSeek با روش دقیق (API داخلی خود سرویس، بدون اسکرول و بدون جاافتادگی) خوانده می‌شوند. Gemini و بقیه‌ی سرویس‌ها با روش عمومی خواندن از صفحه پشتیبانی می‌شوند. Service support: ChatGPT, Claude and DeepSeek are read the precise way (each service's own internal API — no scrolling, no gaps). Gemini and others are supported through generic page reading.

سوالات پرتکرارFAQ & troubleshooting

رفع اشکالCommon issues
افزونه می‌گوید «مکالمه‌ای پیدا نشد»The extension says “No conversation found”
یک چت واقعی را باز کن (نه صفحه‌ی لیست)، مطمئن شو لاگینی، صفحه را با F5 رفرش کن و دوباره افزونه را باز کن. دکمه‌ی ↻ هم صفحه را دوباره می‌خواند.Open a real chat (not the list page), make sure you're signed in, refresh with F5, then reopen the extension. The ↻ button also re-reads the page.
حالت را عوض کردم ولی خروجی تغییر نکردI changed the mode but the output didn't update
دکمه‌ی ↻ را بزن تا دوباره خوانده و با حالت جدید ساخته شود.Press ↻ to re-read and regenerate with the new mode.
ویندوز موقع اجرای برنامه هشدار امنیتی دادWindows showed a security warning when I ran the app
این SmartScreen است چون فایل امضای تجاری ندارد. روی More info → Run anyway بزن. مشکلی برای برنامه نیست.That's SmartScreen because the file isn't commercially signed. Click More info → Run anyway. The app is fine.
آیا برای استفاده از افزونه کلید API لازم است؟Do I need an API key to use the extension?
نه. خواندن و ساختن بریفینگ کاملاً بدون کلید کار می‌کند. کلید API فقط برای قابلیت اختیاری «دقیق‌سازی context با AI» لازم است.No. Reading and building the briefing work with no key at all. An API key is only for the optional “refine context with AI” feature.
تفاوت افزونه و نرم‌افزار دسکتاپ چیست؟What's the difference between the extension and the desktop app?
افزونه مکالمه را از مرورگر می‌خواند. نرم‌افزار دسکتاپ مکالمه‌ی خوانده‌شده (یا هر فایل/متن) را تحلیل، ویرایش و بسته‌بندی می‌کند. برای کار ساده فقط افزونه کافی است.The extension reads the conversation from the browser. The desktop app analyzes, edits and packages a read conversation (or any file/text). For simple use, the extension alone is enough.
پوشه‌ی extension را جابه‌جا یا پاک کنم اشکالی دارد؟Can I move or delete the extension folder?
تا وقتی افزونه در کروم نصب است، آن پوشه باید سر جایش بماند. اگر جابه‌جایش کنی باید دوباره از chrome://extensions با «Load unpacked» معرفی‌اش کنی.While it's loaded in Chrome, that folder must stay put. If you move it, re-add it from chrome://extensions with “Load unpacked”.
